### What's new since v0.2.0-alpha

- **Folders.** Group stickers in folders you name, from a sticker's details, and browse them from a
  row of chips on the main screen and in the keyboard. Searching inside a folder looks only at that
  folder's stickers.
- **Back up and restore**, for moving to another phone (About → Back up). Tags, descriptions, stars,
  hidden picture tags, folders, how often you used each sticker, search history and test searches
  go into one file you choose, with an optional password. People's names only if you tick the box.
  What the new phone can't match yet waits until its stickers are read.
- **Learn from your chats.** Import a WhatsApp chat export (Smart search, or WhatsApp's Export chat)
  and the app learns what you use each sticker for, from the messages written just before you sent
  it. Only averaged numbers are kept, never the messages. Forget them any time.
- **Better meaning search.** Separate "what it says" and "what it shows" vectors, a cut-off that
  adapts to each search, and no more whole packs flooding the results. Results no longer jitter
  while indexing runs in the background.
- **Animated stickers send again from the keyboard.** Big animated stickers, or ones WhatsApp's
  rules don't allow (over 500 KB, not 512 × 512, longer than 10 s, frames under 8 ms), are fitted
  to the rules for that send. It takes a few seconds the first time and is instant after.
- **Tag suggestions stay put.** A sticker you remove never comes back for that tag, and the list
  doesn't jump around while you work through it.
- **Getting started with Pili.** A checklist that ticks itself off, one-time hints on each screen
  and quirky tips while stickers are read. About → Show tips again brings them back.
- **Safer everywhere.** Stickers are recognized by their exact content, not just how they look, so
  restores and tag edits can't land on a look-alike. The keyboard never saves text read from the
  chat box, even after you edit it. Backup files are size-limited and checked, and restoring while
  deleting face data can't clash.
- **Problem report** now shows how WhatsApp read the last stickers sent from the keyboard
  (counts and times only).

**Good to know:** the first start after updating reads each sticker's file once in the background,
while charging, to tell exact copies apart. The app is about 1 MB bigger: it now includes Google's
libwebp (BSD-3-Clause) to fit animated stickers.
